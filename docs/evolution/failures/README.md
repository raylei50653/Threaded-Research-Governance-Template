## Why these are the load-bearing part

A model whose history contains only additions has not been tested. The evidence that an
abstraction is doing work is that a neighbouring one was found not to be, and removed.

And the reason **03 keeps its own status** rather than being rounded up to "retracted": a
proposed direction is not an adjudicated one. Calling an open issue a retraction would be
the plan-becomes-fact error that [primitive 01](../../primitives/01-authority-separation.md)
exists to prevent, committed on the page that documents it.
